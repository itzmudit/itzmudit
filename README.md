### `$ whoami`

I build tools where electronics meets software: a circuit solver in C, an AI tool that attacks chatbots to find their weak spots, and the frontend for a road-health prediction system. Lately I've been learning how EEG and EMG signals are read and used to control hardware.

**Try my work instead of reading about it:** my [portfolio](https://itzmudit.github.io) has a working shell, MiniSPICE running live in the browser, and an OpenCV image lab.

#### [CaughtBot](https://github.com/itzmudit/CaughtBot)
`Python` `Streamlit` `Groq` `Pydantic` `SQLite`

Red-teams AI chatbots. Fires **40 prompt-injection and jailbreak attacks** in 6 categories, has a second LLM judge every reply, writes PDF reports, and **auto-hardens** the bot's prompt, keeping a fix only if the measured score goes up.

**Security score on the demo bot: `22 → 62`** · built at Hackin' Summer 2026

</td>
<td width="50%" valign="top">

#### [MiniSPICE](https://github.com/itzmudit/MiniSPICE)
`C` `nodal analysis` `Gaussian elimination`

A DC circuit solver in a single C file. Builds the conductance matrix from KCL, solves it with **partial pivoting**, detects floating nodes, and checks that power supplied equals power used. SDF Lab-1, team of 4.

**[▶ Run it in your browser](https://itzmudit.github.io/#lab)**
